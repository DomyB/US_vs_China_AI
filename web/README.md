# The site

The public interface of the tracker: a Next.js 15 app (React 19, Tailwind v4, Observable Plot, MapLibre) that reads the JSON files the pipeline exports into `public/data/real/` and, for anything the export has not produced yet, the seeded sample set in `public/data/sample/`. Every block says which layer it shows: facts, model output, interpretation or sample. Deployed on Vercel (Hobby tier) from `main`, root directory `web`.

## Commands

| Command | What it does |
|---|---|
| `npm run dev` | Development server at http://localhost:3000 (copies MapLibre's worker into `public/vendor/` first) |
| `npm run build`, `npm run start` | Production build and server; what Vercel runs |
| `npm run lint`, `npm run typecheck`, `npm test` | ESLint, `tsc --noEmit`, Vitest (tests under `src/**/__tests__/`) |
| `npm run og` | Renders `public/og.png` (1200×630) and `src/app/apple-icon.png` with Playwright's Chromium from the hero drawing and the light tokens; `CHROMIUM_PATH=…` names a Chrome binary when Playwright's own is not installed |
| `node scripts/ui-check.mjs` | Browser checks against a running build (`BASE`, default http://localhost:3000): console and page errors, horizontal overflow, the token colours, 16px inputs on touch screens, the context bar on the explore page at three widths and its "Who buys" view, every exhibit's reading lines and the page guides, favicon and social metadata, every tour step, reduced motion, the social image's size; screenshots to `OUT` |

Before a push: `npm run lint && npm run typecheck && npm test && npm run build`, then the ui-check on `npm run start`.

## Where things are

- `src/app/`: the routes (`/` is the story, `/explore` the map with its context bar, `/contested` the arguments page (claims tested on the record, `lib/contested.ts`), `/country` the case-file index and `/country/[iso3]` a case file, `/lab` the scenario studio and findings, `/archive` the hub for `/region`, `/methodology` and `/sources`; `/insights` redirects to `/lab` and a link to `/` carrying map parameters redirects to `/explore`, both in `next.config.ts`), `not-found.tsx`, `error.tsx`, a `loading.tsx` per data route, `icon.svg` and `apple-icon.png`, and `globals.css` with the design tokens for both colour schemes, Tailwind's layers and the three blocks kept outside them on purpose (MapLibre's controls, coarse-pointer sizes, reduced motion).
- `src/components/`: `story/` (the cold open, the chapter frame with its exhibits, meters and guess-first sliders, the nine chapters, the progress rail), `home/` (map page, context bar, legend card, drawer, intro card, overview, comparison; `lib/buyers.ts` holds the "who buys" grid shared with the home map), `archive/` (the case-file index and the hub), `panel/` (the country tabs), `region/`, `insights/`, `charts/` (`PlotFigure` with its expand dialog, data table and the frame glyph for model-output figures; `Curtain` for "no source after <year>"), `controls/`, `tour/`, `ui/` (buttons and pills live in CSS; icons, skeletons, status strip, theme toggle, logo tile, release line; `EvidenceDrawer` and its `EvidenceButton`, `GlossaryTerm`).
- `src/lib/`: `data.ts` (loaders: one request per file and page load, revalidated by the browser), `story.ts` (every number the story shows, derived from the exports and tested against the committed files in `__tests__/story.test.ts`), `provenance.ts` (what an exhibit rests on: tables, ids, sources, last years, model, evidence; `provenanceFor` for the case-file tabs and `labProvenance` for the Lab blocks), `glossary.ts` (the terms the drawer and the methods page share), `sources.ts` and `sources.server.ts` (the registry is read from disk by server components and fetched once by the client; it is in no bundle), `site.ts`, `types.ts`, `constants.ts`, `format.ts`, `scenario.ts`, `sources.ts`, `motion.ts`, `theme.ts`, `useRealMeta.ts`, `useMediaQuery.ts`.
- `public/data/real/` is written by the pipeline's export step in GitHub Actions and committed by the workflow; never edit it by hand. `public/data/sample/` comes from `pipeline/scripts/make_sample_data.py` (seeded).
- `scripts/`: `copy-maplibre-worker.mjs` (runs before dev and build), `render-og.mjs` with `og/template.html`, `ui-check.mjs`, `build_geo.sh` (the basemap).

## Conventions

- Facts, model outputs and interpretation stay visually separate (`LayerLabel`, `DataLayerTag`); every number keeps its source; nothing is estimated silently and missing data is shown as missing.
- Colours are the tokens in `globals.css`. US blue and China vermilion mean the two actors and nothing else; the interface accent is the ink; `--danger` marks errors.
- Element rules go in `@layer base`, our classes in `@layer components`, so Tailwind utilities keep the last word; a rule left outside the layers must say why.
- Motion carries information and is off under `prefers-reduced-motion` (`src/lib/motion.ts`).
- Text is sentence case, including buttons; numbers are tabular; headings are the serif at the base-layer sizes unless a page says otherwise.
- The story's numbers come from the same files as the pages it links to; `story.json` carries only what no other file has (the quoted records that live in country files and the per-mineral share series). A reader's guess on a "guess first" slider stays in their browser.
- The media files (`public/data/real/media/<ISO3>.json`) carry the kept headlines, the yearly counts (`volume`) and a per-source monthly `history` (GDELT, Media Cloud, the outlets' feeds, each kept apart); the Media tab's "Coverage over time, by source" exhibit and its year-range filter read them, and `lib/data.ts` merges them over the sample without flipping the layer to real until tone is coded.
- `/votes-and-ore` (`components/alignment/`, `lib/alignment.ts`): the political-alignment and economic-ties sub-indices set against each other (two maps, a quadrant chart, the movers, small multiples), every number derived in the browser from `index.json` and tested in `lib/__tests__/alignment.test.ts`.
- `/step-by-step` (`components/stepbystep/`, `lib/geometry.ts`): the walkthrough pages. `Walkthrough.tsx` is the frame (numbered stages, the stage in `?stage=`, arrow keys); `WordsView.tsx` reads `words.json` (the record in `?doc=`) and `IndexGeometryView.tsx` reads `components.json` (`?country=&year=&actor=`); cosine similarity, the normalisation, the composite, distances and the small principal-component analysis are in `lib/geometry.ts`, tested in `lib/__tests__/geometry.test.ts`. A map whose points are clickable wraps its figure in `.records-map` so the tooltip layer passes clicks through.
- `/` (`components/overview/OverviewPage.tsx`): the home as the prototype's overview; the bivariate hero map reuses `SouthAmericaMap` with fills from `flows.json`; the story is at `/story` (`story/StoryPage.tsx`). The design system (DECISIONS 96) lives in `app/globals.css`: tokens, type scale, `.card`/`.panel`, `.btn`, `.input`, `.chip`, `.kind-*`, `.stat`, `.seg`, `.pill`.
- `/stage` (`components/stage/StageView.tsx`, `lib/stage.ts`): the team's prototype as a section, read from `public/data/companion/prototype/` (DECISIONS 95); `tradeSeries` is the prototype's aggregation rule ported line for line (tested against its four stated numbers), `fourNumbers`, `termAt`, `termSegments` and `share` select and label. The prototype itself is served untouched at `/prototype` (`public/prototype/index.html`, redirect in `next.config.ts`).
- `/denial` (`components/denial/DenialView.tsx`, `lib/denial.ts`): the companion project "Denial without Substitution", read from its own files under `public/data/companion/denial/` (DECISIONS 94); `verdictKind`, `stageOf`, `eventsByYear`, `govCells`, `tradeLean` and `synthRows` (tested) select and label, never rescore.
- `/routes` (`components/routes/RoutesView.tsx`, `lib/routes.ts`): where the ore goes, from `routes.json`; `originsFor`, `destinationsFor` and `indirectFor` (tested) rank the exported cells and bound the indirect route by the smaller leg; the same component is embedded in the whole-picture chapter and in each mineral case file.
- `/what-we-know` (`components/knowledge/WhatWeKnowView.tsx`, `lib/literature.ts`, `lib/verdicts.ts`): the per-measure verdicts (`verdicts`, tested) computed from the overview series, the literature set against the record, and the closing reading; the story's chapter 10 (`story/Ch10Winning.tsx`, `story/Verdicts.tsx`) shows the same verdicts.
- `/mineral` and `/mineral/[id]` (`components/mineral/`, `lib/minerals.ts`): the mineral case files read from `minerals.json` and `minerals/<id>.json`; `mainSeries` picks one unit per country for the production chart, `unitsByCountries` orders the units so a chart opens on the most shared one, `latestExports` and `exportsByYear` build the buyers exhibits.
- `/step-by-step/classifier` (`components/stepbystep/ClassifierView.tsx`, `lib/classifier.ts`): the stance head trained in the browser from `classifier.json` (the example in `?ex=<doc_id>:<actor>`); the seeded start, softmax, cross-entropy, the full-batch step with balanced weights and the L2 penalty, the training loop with its history, accuracy, macro F1, the confusion matrix and the per-input contributions are in `lib/classifier.ts`, tested in `lib/__tests__/classifier.test.ts`.
- The year range comes from `public/data/real/period.json` (`YEAR_MIN`, `YEAR_MAX`, `PERIOD_FROM` in `lib/constants.ts`), written by the pipeline's export; no component hard-codes the first or last year.
- Every exhibit carries an evidence button that opens the drawer (`ui/EvidenceDrawer.tsx`): layer, tables linked to the methods page, ids, sources with reliability and liveness, last year of each input, model and validation, status, evidence meter and caveat, show as table, explore, copy link, argue with this reading. Styles for the trust layer are in `src/app/trust.css`, imported after `globals.css`.

# Decisions

Every major choice, when it was made, and why. Newest at the bottom. Reversals are
appended, not edited.

| # | Date | Decision | Why | Alternatives considered |
|---|---|---|---|---|
| 1 | 2026-10-01 | Budget is $0. No paid APIs, data feeds, hosting tiers or model APIs. | School project; the professor will not accept paid services. | Paid LLM classification (~$150–650 backfill), paid lithium price feeds, Vercel Pro. All excluded. |
| 2 | 2026-10-01 | Pipeline and site are separated: Python pipelines produce versioned Parquet and JSON; the Next.js site reads static JSON. No live database. | Reproducibility, zero hosting cost, fast site. A managed Postgres free tier (0.5 GB) is too small for the news metadata anyway. | Managed Postgres (Neon/Supabase) queried live by the site. |
| 3 | 2026-10-01 | DuckDB + Parquet is the analytical warehouse. Schema documented in docs/PHASE0_PLAN.md section 4 and mirrored in `pipeline/schema`. | Versionable files, zero cost, same SQL schema portable to Postgres later. | Postgres from day one (see 2). |
| 4 | 2026-10-01 | All ingestion and model inference run in GitHub Actions (public repo, unlimited minutes). The development sandbox has no general outbound network access. | The sandbox's egress policy only reaches GitHub and PyPI; Actions runners have open egress and are the scheduled runtime anyway. | Widening the sandbox network policy. |
| 5 | 2026-10-01 | Text classification uses open-weight models only: a multilingual encoder (XLM-R or mDeBERTa) fine-tuned on a hand-coded codebook sample, bootstrapped with zero-shot NLI, trained on Colab/Kaggle free GPUs, run on Actions CPU. The validation sample is coded by the project owner and by Claude inside development sessions (no API calls). | Decision 1. Established method in political text analysis; quality then depends on the coded sample rather than on money. | Anthropic Batch API (Haiku/Sonnet/Opus). |
| 6 | 2026-10-01 | Phase 6 analysis text is template-driven from named indicators plus a separate human-written interpretation layer. | Every sentence traces to an indicator; more defensible academically than generated prose; free. | Open-model-drafted prose on Colab (still possible later, optional). |
| 7 | 2026-10-01 | Hosting on the project owner's existing Vercel account (Hobby tier, free `*.vercel.app` URL), site root directory `web/`. | Decision 1; non-commercial use qualifies for Hobby. | Cloudflare Pages (OpenNext adapter needed), Vercel Pro. |
| 8 | 2026-10-01 | Map boundaries from Natural Earth 1:10m `admin_0_map_units` (public domain) so French Guiana is its own polygon, rendered and labeled as French territory outside the analysis. | `admin_0_countries` merges French Guiana into France; `topojson/world-atlas` is archived (Natural Earth 4.1). | world-atlas npm package. |
| 9 | 2026-10-01 | Mineral list and HS6 mapping live in `pipeline/config/minerals.yaml` and `hs_codes.yaml`; default UI set is the nine minerals from the brief, extended set covers other US/Chinese list minerals produced or explored in the region. The 2025 USGS list (60 minerals) is the reference, so copper and silver count as critical. | Brief section 3 asks for a configurable list. | Hard-coding in the UI. |
| 10 | 2026-10-01 | Source registry is `pipeline/config/sources.yaml`; `SOURCES.md` and the site's Sources page are generated from it and never edited by hand. | Single source of truth for URL, coverage, license, reliability rating, refresh schedule. | Maintaining SOURCES.md manually. |
| 11 | 2026-10-01 | Dead or moved sources from the brief are replaced as listed in docs/PHASE0_PLAN.md section 2.1 (IMF DOTS→IMTS; BU/Dialogue Chinese loans→BU CODF + AidData; EXIM→data.gov CSV; MSP→FORGE; Georgetown PDBA→SIGLA; UNCTAD bilateral FDI→IMF DIP). | Verified during Phase 0 (search-based; direct checks happen in the first Actions run). | Keeping dead sources listed as gaps. |
| 12 | 2026-10-01 | SEDAR+ and HKEXnews are never scraped; their terms prohibit it. Canadian and Hong Kong filings come from SEC cross-listings and company investor-relations pages. | Brief section 4: respect terms of use. | Community scrapers that violate the terms. |
| 13 | 2026-10-01 | Lithium prices: USGS annual averages plus customs-derived unit values (value ÷ quantity for HS 2836.91 and 2825.20), labeled "implicit realized price". | No free, licensed lithium benchmark exists; paid feeds excluded by decision 1. | Scraping investing.com or Trading Economics (terms prohibit). |
| 14 | 2026-10-01 | Phase 1 sample data is generated by a seeded script (`pipeline/scripts/make_sample_data.py`), stored under `web/public/data/sample/`, and every panel shows a SAMPLE DATA banner until real data replaces it. | Brief section 6; prevents sample numbers being mistaken for findings. | Hand-written fixtures. |
| 15 | 2026-10-01 | Ingestion architecture: `fetch` writes immutable dated raw snapshots with a manifest (URL, params, status, SHA-256, retrieval time); `parse` is a pure function from snapshot to schema-validated DataFrames; `load` writes one Parquet file per source and table. | Reproducibility and testability: parsers run on recorded fixtures with no network; every row keeps provenance. | Calling client libraries directly inside parsers (hides URLs and makes fixtures impossible). |
| 16 | 2026-10-01 | Adapters are written against documented response formats and tested on synthetic fixtures; the first GitHub Actions run records trimmed real responses (`python -m scm fixtures`) that replace them. | The development sandbox cannot reach the sources; Actions runners can. | Waiting for network access before writing any adapter. |
| 17 | 2026-10-01 | Comtrade is pulled keyless from the public preview endpoint, one call per reporter and year (and per partner group for US/China mirrors), each under the 500-record cap. A `COMTRADE_KEY` secret switches to the subscription endpoint without code changes. | $0 budget; annual HS6 data for 12 reporters fits the free limits. | Requiring a key before any trade data flows. |
| 18 | 2026-10-01 | Secret-gated adapters (Congress.gov, Census, BU CODF) report `skipped` until their secret exists; the BU CODF file is never committed and only aggregates reach the site. | Nothing blocks on registrations; the CODF data-use agreement forbids redistribution. | Committing third-party files to the public repository. |
| 19 | 2026-10-01 | The site resolves each layer separately: facts (actions, governance) from `web/public/data/real/` when `coverage.json` says the country has data, otherwise sample; model outputs, parliament and media stay sample until Phases 3-5. The banner states which layers are real. | Honest labelling while real data arrives incrementally. | Replacing the whole sample dataset at once. |
| 20 | 2026-10-01 | Finance events reported by several databases are clustered conservatively (same country, year, origin; amount within 10 percent; never two rows from the same source) and all source ids are kept. | Brief 7i: deduplicate deals but keep every source link. | Fuzzy name matching across databases (deferred; too error-prone without review). |
| 21 | 2026-10-01 | Data releases: Parquet warehouse tarball attached to a GitHub Release tagged `data-vYYYY.MM.DD` by the monthly workflow; site JSON committed to git. | Versioned, reproducible, free. | git-lfs (quota-limited), DVC with a paid remote. |
| 22 | 2026-10-01 | Every recorded URL (manifests, fixtures, `source_record_url`) is stripped of credential-bearing query parameters (presigned S3/Azure signatures, API keys) by `scm.http.clean_url`; redirect targets are kept separately from the requested URL. | Harvard Dataverse redirects to presigned S3 links whose access-key id tripped GitHub push protection and blocked a data commit; the stable request URL is also the better citation. | Allow-listing the token on GitHub (would leave the pattern in the repository). |
| 23 | 2026-10-01 | Sources whose open endpoints broke in the first live runs (EXIM on data.gov, IDB DPI, AEI CGIT) accept a hand-supplied file URL through a repository secret (`EXIM_FILE_URL`, `DPI_FILE_URL`, `CGIT_FILE_URL`) after the automatic paths fail. | Keeps the pipeline reproducible (the URL is recorded) without waiting on third-party site fixes. | Committing the files (license and size), or dropping the sources. |
| 24 | 2026-10-01 | Worldwide Governance Indicators are read from the World Bank Data360 API (dataset `WB_WGI`, ids discovered from its indicator listing, estimate breakdown only). | The classic v2 API and the govindicators.org download both failed from a runner in October 2026; Data360 is the World Bank's current platform and answers JSON without a key. | Scraping govindicators.org with a headless browser; dropping WGI (V-Dem alone). |
| 25 | 2026-10-02 | One `document` table holds legislative records and news (`doc_type`); news rows must have no `summary` (a schema check), so the headline-only rule for press is enforced by validation, not convention. | Brief section 4; one keyword filter, one dedup path and one export path for all text records. | A separate media table duplicating most columns. |
| 26 | 2026-10-02 | Legislative records and headlines are keyword-filtered at ingestion (mining and mineral terms in es/pt/en/nl, China and US actor terms); every stored row records the terms that matched and the filter version. | Full legislative corpora and feeds are far larger than the topic; the audit trail keeps recall fixes traceable. | Storing everything (size, licence exposure) or classifying with a model before storage (Phase 3). |
| 27 | 2026-10-02 | Press history comes from the GDELT 2.0 DOC API (keyless), restricted to the outlets in the registry and re-filtered on the headline; current items come from each outlet's RSS feed. GDELT dates are indexing dates and are labelled `seen`. | RSS feeds hold only recent items; GDELT is free, covers 2017 onward and names the outlet domain. Media Cloud needs a key and stays optional. | Scraping outlet archives (terms, paywalls). |
| 28 | 2026-10-02 | Tables that accumulate (document, vote, vote_member, concession, media_volume) are merged on a key with the previously released Parquet; the first-seen row wins so `retrieved_at` records the first observation. Press runs weekly. | Feeds are ephemeral; the data release is already the persistence layer. A failed run publishes no release, so one week can be lost (documented). | A database service (not free) or committing Parquet to git (size). |
| 29 | 2026-10-02 | Every HTML, feed and web-service host is fetched only after its robots.txt allows it (crawl-delay honoured); hosts that answer 403 to automated clients or whose terms forbid reuse (Colombia's Senado) are never fetched. | Brief section 4. | Rotating user agents or proxies (never). |
| 30 | 2026-10-02 | Real legislative records and headlines are shown on the site as soon as they are ingested, with stance, tone and translation marked `not yet classified`; the stance series, attention and narrative charts stay labelled SAMPLE until Phase 3. The layer is called `facts_only`. | Owner's decision: honest, visible progress without mixing facts and model outputs. | Hiding the records until classification exists. |
| 31 | 2026-10-02 | National mining cadastres go into a `concession` table (title, holder, minerals, status, dates, area, centroid), not into `deal_event`. | Cadastres hold thousands of title records without actor origin; deal_event is for dated actor-level events. Phase 4 links holders to actors. | Forcing concessions into deal_event. |
| 32 | 2026-10-02 | Bolivia, Guyana, Suriname and Venezuela have no machine-readable legislative records; the exporter writes an explicit note per country and the UI shows it instead of an empty list. | Brief: missing data is shown as missing, never as zero. | Scraping PDFs (Phase 3 at the earliest). |
| 33 | 2026-10-03 | GDELT fetching is bounded per run (time budget, throttle cap, 10 s spacing) and uses `sourcelang:` for non-English queries; history fills incrementally from the weekly press run, with a long manual backfill as the option when the runner address is not throttled. | Two runs spent four hours mostly sleeping on HTTP 429 and risked the five-hour job limit; one source must never starve a run. | Paying for a GDELT BigQuery export (not free), or dropping history. |
| 34 | 2026-10-03 | Ingestion workflows are dispatched from `main`, which is fast-forwarded from the development branch after every push; data commits land on `main` and trigger the production deployment. | Owner's instruction; Vercel deploys the default branch. | Keeping data on the development branch and merging periodically. |
| 35 | 2026-10-03 | Every adapter runs under a wall-clock budget (`SCM_ADAPTER_BUDGET_MIN`, default 120 minutes; SIGALRM raises `AdapterTimeout` inside the adapter, sleeps and socket waits included) and records `failed` when it is spent; the Comtrade adapter also stops after three consecutive calls refused with 429/403/503, naming the spent daily quota. | The first scheduled run spent five hours inside Comtrade (every preview call refused after a dispatch had fetched Comtrade an hour earlier) and was cancelled at the job limit with nothing committed. A failed adapter keeps the previous release's rows; a cancelled job keeps nothing. | Longer job limits (six hours is the ceiling) or per-adapter threads (parse memory doubles). |
